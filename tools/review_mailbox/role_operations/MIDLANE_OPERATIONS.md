Load only the section needed by the current checkpoint. The compact role task
and `AGENTS.md` remain authoritative. This file supplies command choreography.

Start each iteration with `python -B tools\coordination_inbox\coordination_inbox.py chat-delta --consumer midlane`. Never pass generated reply prose inline through PowerShell because dollar amounts and other metacharacters can be altered. Chat is current operator prose, not a formal package-bound confirmation, and cannot replace submission, terminal, lifecycle, frozen-byte, ownership, or safety commands.

An operator-authored chat message is sufficient authority for the exact ordinary in-scope action it names; do not require the same request in another local channel. If it explicitly asks to add a qualifying workflow defect to the issues database, read `REPORT_ISSUES_POLICY.txt`, prepare the bounded issue JSON, run `python -B tools\review_mailbox\report_issues.py record --issue-file <PATH> --actor midlane`, and reply with the issue ID, key, and status. Coordination INFORMATION is not a workflow-issue record. Preserve every formal package-bound confirmation and protected-action boundary above.

For new signals use `coordination_inbox.py list-open`, then `post --type INFORMATION --scope-kind <TARGET_OR_PACKAGE> --scope-ref <EXACT_SCOPE> --body "<BOUNDED FACT>"` or `post --type ACTION_REQUEST ... --requested-action "<ONE EXACT ACTION>"`. Add `--reply-to <PARENT_ID>` when INFORMATION answers an existing message. ACTION_REQUEST is only for an exact action blocked on fresh operator authority; status, advice, facts, normal lifecycle choices, and already-authorized work are INFORMATION. Never write its SQLite database directly; never dual-write, ask package questions there, or take the requested action. Posting grants no authority; approval is bound to the exact message, revision, and action.

`notes/review_mailbox/MIDLANE_TO_HUNTER.md` is an explicit fallback only when the CLI is unavailable; never both. Do not take requested action without explicit operator authorization. Report each legacy response once.
